# L'Atelier des Rêves — tutuBlog

**L'Atelier des Rêves** est mon site web personnel, un petit espace où je rassemble et partage mes créations, mes projets et mes passions.

On y retrouve notamment :
- **Jeux vidéo** : mes projets de développement et créations autour du jeu vidéo.
- **Musique** : mes compositions et projets musicaux.
- **Écriture** : mes textes et autres travaux créatifs.
- **Personnages originaux (OCs)** : leurs histoires, univers et fiches de présentation.
- **Blog** : mes réflexions, découvertes et envies du moment.

Ce site est un portfolio créatif, une archive personnelle et un terrain d'expérimentation pour le développement web.

## Technique

Le site est développé en **HTML, CSS et JavaScript**, sans framework, et hébergé gratuitement via **GitHub Pages**.
